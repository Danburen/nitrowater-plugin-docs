# 什么是 VeloChatX

VeloChatX 是一款适用于 Minecraft **Velocity 代理端**的多功能跨服聊天插件，负责把各后端服务器的聊天、提及、私聊与广播连接起来。

> 想直接上手？前往[快速开始](/guide/intro/get-start)。

## 设计特点

- **稳定**：配置缺键时使用默认值，不因单个配置项缺失导致插件无法启动；
- **轻量**：基于自研 WaterAPI、Velocity API、LuckPerms API 与 H2 数据库，不引入额外大型依赖；
- **可诊断**：启动时自检服务器绑定、频道成员与配置版本，并提供 `/vcx status` 查看明细；
- **可维护**：内置配置差异查看、缺失键补齐与旧结构迁移，升级不必手工对照模板。

## 功能

### 跨服聊天

玩家在后端服务器发送消息时，VeloChatX 会按配置的格式转发给**其他服务器**的玩家。

::: warning
跨服聊天只负责转发其他服务器的消息。玩家在自己子服内看到的聊天，以及子服内部的聊天管理，本插件不做处理。
:::

### 频道（分区聊天）

可以把服务器分配到不同频道：

- 同一频道内的服务器消息互通；
- 频道外的服务器互相隔离；
- 通过 `channels.global` 决定是否全服互通。

一个服务器可以加入多个频道，具体见[跨服聊天与频道配置](/guide/config/cross-server-chat)。

### 跨服私聊与提及

- `/vcmsg`：玩家之间一对一私聊，其他玩家不可见（控制台也可以发送）；
- `/mention`：提醒某个玩家，支持屏幕标题与提示音。

### 玩家屏蔽

玩家可以用 `/vcx block` 屏蔽其他玩家的聊天、提及与私聊，屏蔽关系保存在数据库中，重启后仍然有效。

### 违禁词过滤

在转发到其他服务器之前检查消息内容；命中违禁词时不转发，并可按配置记录到控制台。

### 定时广播

按固定间隔向各服务器发送公告，支持：

- 全局广播与分区广播合并；
- 每个频道/服务器独立配置消息与前缀；
- 随机抽取消息，避免每次都是同一句。

### 玩家进出广播

玩家进入/离开代理服、后端服务器或切换频道时发送提示，支持：

- 按层级控制（频道切换优先于后端进出）；
- 自定义发送范围（本服 / 同频道 / 全代理）；
- 首次进入的欢迎消息。

### Tab 列表

接管玩家列表，在每个玩家名前显示所在服务器，并统一 header/footer：

- 支持动态刷新频率（在线人数越多刷新越慢）；
- 玩家进出时立即刷新条目与人数统计。

### 服务器状态占位符

提供服务器、频道、在线人数、玩家延迟等占位符，详见[占位符参考](/reference/placeholder)。

### 配置维护

- `/vcx config diff`：查看与内置模板的差异；
- `/vcx config update`：补齐新增配置项；
- `/vcx config migration`：迁移旧版结构；
- `/vcx reload`：热重载并重排定时任务。

详见[配置维护与升级](/guide/config/maintenance)。
